# 파산 버튜버

90초 라이브 한 판으로 이번 주 청구를 막거나, 못 막으면 끝나는 세로 2D 프로토타입이다.

**Unity 6000.5.9f1** (`b57deb96f08d`) · **`Assets/Scenes/Title.unity`** · 브랜치 **`cursor/week1-playable-loop-133f`**

숫자·연출은 이 브랜치에 박혀 있다. 노트북 클론에서는 에디터만 맞추면 바로 플레이할 수 있다.

## Unity에서 열기

1. Unity Hub에서 **6000.5.9f1** (`b57deb96f08d`)을 설치한다.
2. **Add** → 이 저장소 루트를 연다. Built-in 2D, URP/HDRP 없음.
3. `Assets/Scenes/Title.unity`를 연 뒤 Play. 폰은 세로. 안드로이드 빌드는 Portrait로 열린다.

씬 네 장: `Title` → `WeekStart` → `LiveStream` → `Settlement`. 타이틀 로고가 살짝 펄스한다. 세이브가 있으면 **이어하기 n일차** + 현금/부채(청구를 알면 현금 부족은 빨강, 부채는 골드. 어제 헤드라인). **새 방송 시작**은 **진행 중인 n일차를 지울까?** 확인 후 지운다.

## 조작

라이브에서 화살표 · A/S/D/F · WASD · 화면 패드가 같은 노트에 들어간다. 패드/키를 누르면 그 패드가 0.08초 밝아지고 **입력됨**이 뜬다.

| 입력 | 동작 |
|---|---|
| ← / A / 왼쪽 패드 | 긍정 |
| ↓ / S / 아래 패드 | 공감 |
| → / D / 오른쪽 패드 | 웃음 |
| ↑ / F / W / 감사 패드 | 감사 |
| Space / Enter **떼면** 한 번 | 슈퍼챗 놓기 (홀드 연타 없음) |
| 1 / 2 / 3 / 4 | 이벤트 QTE (안티 웨이브 / 장비 렉, 빛나는 키) |
| 1일차 코치 | 새 런 첫 라이브만. 노트가 히트바에서 멈추고 **← 긍정** 같은 한 줄이 뜬다. 성공 3회 또는 8초면 끝. |

## 한 판 루프

**Title** → **WeekStart** **오늘 청구**가 빨간 칸에서 0.25초 슬램(현금이 청구보다 적으면 **현금**이 경고 빨강 + **청구보다 부족**. 막히면 그대로) → 청구 카드 → 콘텐츠 픽(토크 편하게 잡담 / 게임 같이 깨자 / 노래 고음 승부 / 리액션 같이 보자) → **90초 라이브** → **Settlement** 헤드라인 / 편지 / 주차 카드 → 클리어 또는 파산.

라이브는 **ON AIR** / **방송 시작**(0.6초) 뒤에 HUD가 이어진다. 1일차 코치는 그 다음. 90초가 끝나면 **방송 종료** 컷(검정 플래시 · LIVE 점 꺼짐, 0.5초) 뒤 정산.

라이브 HUD에 있는 것:

- 지금 수입 · 오늘 청구 · 파산까지 — 슈퍼챗 ₩이 수입 칸으로 날아간다. 빗나가면 크랙. 성공 노트는 지금 수입 옆에 **+₩**. 마지막 10초는 시계가 빨강으로 뛰며 **10…9…** 초마다 틱. 0이면 **종료**.
- 떨어지는 채팅은 한국어 닉 + 대사. 히트라인 0.15초 안(퍼펙트 구간)에 들어온 노트는 밝아진다. 민준 첫 도네는 스탬프.
- 하이프 중 금빛 워시 · 채팅이 기존 카탈로그/닉으로 약 2배 떨어짐(끝나면 원래 속도) · 멘탈 위험/강제 종료 워시 · 시청 ± 팝업. Perfect는 금색 **PERFECT**(0.2초, 큼) + 웹캠 1.08 펀치/흰 플래시 0.12초. Good은 작은 흰색 **GOOD** + 작은 끄덕. 미스는 기존 흔들/스카. 콤보가 오르면 칩이 0.1초 팝(1.15, 5+면 1.22). 콤보 2 이상에서 미스면 **콤보 끊김**(빨강 0.25초) 뒤 COMBO 0. 첫 노트 미스는 그냥 Miss.
- 위협 오버레이 · 이벤트 카드 · 청구를 넘기는 순간 **청구 커버** 금빛 슬램(한 판 한 번, 이후 초록 고정).

정산: **오늘 헤드라인** → **오늘 수입**이 0에서 실지급까지 0.6초 카운트(청구를 넘기면 기존 커버 골드 한 번. 못 막으면 스냅 뒤 **청구 미달** 빨강 0.35초) → 부채가 늘었으면 **부채**가 전날 금액에서 오늘 금액까지 0.4초 빨강 카운트(그대로거나 줄면 숫자만, 줄면 약한 초록) → **멘탈**이 빠졌으면 아침 값에서 오늘 값까지 0.35초 지친 빨강 카운트(오르면 작은 초록 틱, 그대로면 숫자만) → 편지 → 그 주 시스템 카드. 다음날 아침 청구 슬램 위에 **어제: …** (1일차·재시작은 없음). 5/10/15/20/25일 아침은 **마지막 날** / **n주차 마지막** 배너. 주 클리어/파산은 전용 화면.

## 2~5주차 (있는 그대로)

1주차는 청구·멘탈·콤보·이벤트만. 2주차부터 아래가 정산/라이브에 붙는다. 숫자는 코드에 잠겨 있다.

- **2주차** — 멤버십 스플래시 · 클립 카드.
- **3주차** — 라이벌 듀얼 · 아크릴 해금 · 홍보 카드.
- **4주차** — 에이전시 · 후배 · 스폰서 카드.
- **5주차** — 랭킹 · 콘서트 · 엔딩 루트(`EndingRoot`).

이름 팬은 **민준** / **하은**. 일반 채팅 닉은 `밤샌사람` 같은 풀. 콘텐츠 네 장(토크/게임/노래/리액션)은 청구 슬램 뒤 고른다.

## 플레이테스트 키

에디터 / DEVELOPMENT 빌드만. 켜지면 오른쪽 위에 **DEBUG  F9 다음 주  F10 오늘 스킵**.

- **F9** — 다음 주차(2/3/4/5) 첫날 아침으로 점프한 뒤 세이브. 5주차면 무시. 이미 적힌 **어제** 헤드라인은 그대로 두고, 비어 있으면 오늘 사실로 한 번 적는다.
- **F10** — 남은 방송을 평균 성공 **₩28,000**으로 건너뛰고 정산. 정산 화면에서는 다음날 아침. 하이프 익스플로잇 아님. 스킵도 `lastHeadline`을 남겨 다음날 **어제:** 가 뜬다.

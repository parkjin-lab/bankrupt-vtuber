# 파산 버튜버

VTuber money-defense. Week 1 slice: 매일 청구서가 들이닥치고, 90초 라이브 채팅 QTE로 메우고, 정산한다.

Cute anime-adjacent presentation, harsh red KRW numbers. Built-in 2D (Unity UI Canvas), Unity **6000.5.9f1**.

## Unity에서 열기

1. [Unity Hub](https://unity.com/download)에 **Unity 6000.5.9f1** (changeset `b57deb96f08d`)를 설치한다.
2. Hub → **Add** → 이 폴더(`Assets`, `Packages`, `ProjectSettings`가 있는 루트)를 연다.
3. 첫 임포트 후 **`Assets/Scenes/Title.unity`** 를 더블클릭한다. 이 씬이 시작 씬이다.
4. Play를 누른다. 에디터 스크립트가 Play Mode 시작 씬을 `Title`로 고정하고 Build Settings에 네 씬을 넣는다.

Build Settings 순서:

1. `Assets/Scenes/Title.unity`
2. `Assets/Scenes/WeekStart.unity`
3. `Assets/Scenes/LiveStream.unity`
4. `Assets/Scenes/Settlement.unity`

빈 씬이나 "coming soon" 씬은 없다. `GameManager`는 Play 시 `DontDestroyOnLoad`로 뜨고 루프를 연결한다.

## 1주차 루프

`Title` (타이틀 / 첫 실행 프롤로그) → `WeekStart` (고정비 웨이브) → `LiveStream` (90초 채팅 QTE) → `Settlement` → 다음날 또는 승/패.

안드로이드 세로(9:16)에서는 Title / WeekStart / Settlement / 엔딩·클리어·파산과 멤버십·클립·갈등·지원금 카드가 `Screen.safeArea` 안에 붙고, 두 버튼은 내비 바 위에 남는다. 라이브 패드는 그대로 전폭 5열이다.

1주차 승리 후 **주차 클리어** 스플래시(1주차 생존)를 보고 **다음 주차 시작**으로 6–10일차. 파산은 빨간 **파산** 스탬프. Title / Restart는 항상 1주차 새 런.
정산 첫 화면에는 **오늘 헤드라인**이 붙는다. 청구 커버/미달, 라이벌, 클립, 팬레터, 하이프, 시청 피크 중 실제로 일어난 큰 것 두세 개. 주차 클리어 / 파산 / 엔딩에도 같은 한 줄이 남는다.
라이브 일반 채팅에는 **밤샌사람 / 월세토끼** 같은 짧은 한국어 닉이 붙는다. 슈퍼챗은 닉 + ₩. 민준/하은 금·분홍 라벨은 그대로.
기존 하이프(퍼펙트 9, 12초, 수입 2.5x)가 켜지면 스튜디오가 금색으로 물들고 **하이프 2.5x**와 초 카운트가 크게 뜬다. 콤보 5(1.5x)는 작은 스팅만.
멘탈이 떨어지면 화면이 지친다. 40 이하면 탁한 워시와 피곤한 포즈, 20 이하면 **멘탈 위험**, 0이면 기존 강제 종료(수입 ×0.5) 전에 **강제 종료** 스팅.

청구 슬램 후, 방송 켜기 전에 **오늘 콘텐츠**를 반드시 고른다 (토크 / 게임 / 노래 / 리액션). 라이브 QTE는 그대로다.
1일차 첫 방송만, 처음 몇 초 동안 채팅이 히트바에서 멈추고 색에 맞는 키를 알려준다.
방송 중 안티 웨이브 / 장비 렉이 터지면 화면이 한 번 끊기고, 맞는 숫자 키가 밝게 빛난다.

타이틀: 「파산 버튜버」 / 빚더미에서 최고의 버튜버가 되어라. / 방송 시작 · 조작 설명 (← ↓ → ↑ Space, 1–4).  
세이브가 있으면 **이어서 하기**가 방송 시작 옆에 뜬다. **새 방송 시작**은 세이브를 지우고 1주차부터. 이어서 하기는 그날 청구 전이면 WeekStart, 방송이 끝났으면 정산으로 복귀. Play Mode를 꺼도 런은 `Application.persistentDataPath` JSON에 남는다 (방송 90초 중에는 저장하지 않음).  
1일차·미청구·이번 Play에서 아직 안 봤으면 5–8초 프롤로그(빨간 청구서 더미 + 파산냥) 후 WeekStart. 다음날과, 이번 세션에서 한 번 본 뒤 Restart는 건너뛴다.

- 5일 = 1주차.
- 5일 생존 **그리고** (부채 ≤ ₩30,000 **또는** 현금 ≥ ₩70,000) = 승리.
- 부채 ≥ ₩180,000 = 파산 게임 오버.
- 정산 후 현금이 음수면 그 금액이 부채로 넘어간다.

시작: 현금 ₩45,000 / 부채 ₩50,000 / 멘탈 100/100.  
1주차 매일 고정비 ₩22,000 (월세 8k, 전기+넷 4k, 아바타 라이선스 3k, 식비 5k, 장비 2k) + **오늘의 위협** 하나 (₩4,000–₩12,000: 장비 고장 / 라이벌 견제 / 플랫폼 수수료 / 스캔들 루머 / 인터넷 끊김). 테이블은 `Week1Balance.extraThreats`. 시드는 `runSeed + day`라 Restart마다 주간 순서가 바뀐다.

## 2주차 (6–10일)

1주차 승리 후에만. 1–5일차에는 2주차 숫자를 쓰지 않는다. 리튠: `Assets/Resources/Balance/Week2Balance.asset`.

- 입장: 현금 +₩15,000, 부채 −₩10,000, 멘탈 100.
- 고정비 ₩28,000 (월세 10k / 전기+넷 5k / 라이선스 5k / 식비 6k / 장비 2k). 추가 위협 하루 0–2개: 장비 고장 5–12k @20% / 소액 추가 청구 3–8k @25% / 플랫폼 수수료 3k @15%.
- 2주차 파산: 부채 ≥ ₩220,000. 1주차 파산은 그대로 ₩180,000.
- 클리어: 6–10일 생존 **그리고** (부채 ≤ ₩20,000 **또는** 현금 ≥ ₩110,000) **그리고** 멤버십 해금.
- 멤버십 해금: 최고 시청자 ≥ 40 **또는** 성공 방송 ≥ 4회. 해금 시 8명. 처음 해금되면 정산에 **멤버십 해금** 카드(시작 8명, 정산 때 멤버×₩150). 하이프한 방송 +1 (하루 최대 +2). Miss ≥10이면 −1. 정산 때 `멤버 × ₩150` (90초 틱 아님).
- 2주차의 새 방송 변수 — 정산 **오늘 클립 올릴까?** (올린다 / 패스). 하이프 **그리고** Perfect ≥25일 때만 굴림, 성공 30%. 성공 시 금색으로 ₩30,000 + 시청자 +10. 실패/패스는 조용. 하루 1회.

2주차 클리어 후 **3주차 시작**으로 11–15일차.

## 3주차 (11–15일)

2주차 클리어 후에만. 1–10일차 숫자는 그대로. 리튠: `Assets/Resources/Balance/Week3Balance.asset`.

- 고정비 ₩34,000 (월세 12k / 전기+넷 6k / 라이선스 6k / 식비 7k / 장비 3k). 추가 위협 하루 0–2개: 장비 고장 6–15k @25% / 소액 추가 4–10k @25% / 플랫폼 수수료 4k @20%.
- 3주차 파산: 부채 ≥ ₩260,000.
- 클리어: 11–15일 생존 **그리고** (부채 ≤ ₩15,000 **또는** 현금 ≥ ₩140,000) **그리고** 아크릴 스탠드 해금.
- 라이벌: 12일차 **또는** 최고 시청자 ≥ 55인 그 방송 한 번. 라이벌 시작 25, 자연 +0.9/초. Perfect 시 +0.6 스틸, Miss 시 시청자 −0.8(라이벌이 가져감). 승: ₩20,000 + 시작 시청자 +6. 패: 시작 시청자 −5(1주차 시작 12 바닥) · 멘탈 −12. 그 방송만 라이벌 캠과 시청자 두 바. Perfect는 **스틸 +0.6**, Miss는 라이벌 스틸. 종료 시 금색 **라이벌 승** / 빨간 **라이벌 패**.
- 아크릴 스탠드 1 SKU. 멤버십 해금 **그리고** 현금 ≥ ₩60,000이면 해금, 재고 20(그 20은 원가 선지급). 처음 해금되면 정산에 **아크릴 스탠드 해금** 카드(재고 20, 원가 ₩2,500, 판매 ₩7,000). 추가 생산 개당 ₩2,500(정산 버튼). 가격 ₩7,000. 하루 판매 `floor(멤버×0.4 + 피크×0.08)`, 최소 1, 재고 초과 없음. 그날 팔리면 **아크릴 n개 팔림**.
- 3주차의 새 방송 변수 — **굿즈 홍보 타이밍**. 하이프 또는 55초 창에서 하루 1회. 카드: **지금 아크릴 홍보?** 성공 시 오늘 판매 1.5배. ←/↑ 성공은 **홍보 성공 1.5x**, 실패/패스는 추가 ₩ 없음.

3주차 클리어 후 **4주차 시작**으로 16–20일차.

## 4주차 (16–20일)

3주차 클리어 후에만. 1–15일차 숫자는 그대로. 리튠: `Assets/Resources/Balance/Week4Balance.asset`.

- 고정비 ₩38,000 (월세 14k / 전기+넷 7k / 라이선스 7k / 식비 7k / 장비 3k). 에이전시 설립 후 +₩15,000 → ₩53,000. 추가 위협 하루 0–2개: 장비 고장 8–18k @25% / 소액 5–12k @25% / 수수료 5k @20%.
- 4주차 파산: 부채 ≥ ₩300,000.
- 클리어: 16–20일 생존 **그리고** 에이전시 설립 **그리고** (부채 ≤ ₩10,000 **또는** 현금 ≥ ₩180,000).
- 에이전시: 현금 ≥ ₩100,000 **그리고** 부채 ≤ ₩40,000 **그리고** 아크릴 해금 **그리고** 16일 이상이면 정산에 **에이전시 설립** 카드 ₩40,000 (이후 일 +₩15,000 / 고정비 ₩53,000). 설립 후 한 번 **에이전시 오픈**.
- 주니어 1슬롯. 정산 **후배 스카우트** ₩25,000 1회. 성공 방송은 정산에 **후배 방송 +₩4,000**. 훈련 실패(강제 종료 또는 Miss ≥10) 멘탈 −8.
- 스폰서 1건: 에이전시 설립 **그리고** 최고 시청자 ≥ 70. 활성 5일 동안 매일 +₩10,000.
- 4주차의 새 방송 변수 — **스폰서 멘트 타이밍**. 계약 중에만, 하이프 또는 55초 창에서 하루 1회. 카드: **스폰서 멘트**. ←/↑ 성공은 **계약 유지 +₩3,000**. 실패는 **계약 파기 현금 −₩15,000 멘탈 −12**.

4주차에는 콘서트 / 글로벌이 없다. 4주차 클리어 후 **5주차 시작**으로 21–25일차.

## 5주차 (21–25일, 엔딩 주)

4주차 클리어 후에만. 1–20일차 숫자는 그대로. 리튠: `Assets/Resources/Balance/Week5Balance.asset`. 글로벌 투어는 없다.

- 고정비 솔로 ₩45,000 (월세 15k / 전기+넷 8k / 라이선스 8k / 식비 8k / 장비 6k). 에이전시 운영 +₩15,000 → ₩60,000. 추가 위협 하루 0–2개: 고장 10–20k @30% / 소액 6–15k @25% / 수수료 6k @20%.
- 5주차 파산: 부채 ≥ ₩350,000. 이전 주차 파산 임계값은 그대로.
- 랭킹: 최고 시청자 ≥ 100 **그리고** 22일 이상이면 정산에 **챌린지 랭킹**(나 / 루나벨 / 하츠비 / 네온토끼 오늘 점수). 그날 1위면 **1위 +₩10,000**. 일일 점수 `(피크×3) + (멤버×8) + (오늘 굿즈 판매×4) + (Perfect×2)`를 누적. NPC는 `runSeed + day`.
- 콘서트 1회: 현금 ≥ ₩150,000 **그리고** 최고 시청자 ≥ 90 **그리고** 22일 이상이면 정산 **콘서트 개최** 카드 ₩80,000. 성공 정산은 금색 ₩200,000, 실패는 빨간 **개최비만 날림**.
- 5주차의 새 방송 변수 — **콘서트 퍼포먼스 타이밍**. 카드: **퍼포먼스 지금?** ←/↑ 성공은 **정산 ×1.3**. 실패/무시는 배율 없음.
- 엔딩(25일 정산, 또는 파산/번아웃이면 그 즉시). 자동 우선순위: 파산 > 번아웃 > 솔로 전설 > 에이전시 제국. 에이전시+주니어면 엔딩 화면에서 **후배에게 메인 양도**로 은퇴 프로듀서를 강제할 수 있다(파산/번아웃 제외). 아니면 무명 생존 / 계속 활동. 전용 엔딩 화면 후 Restart.

## 팬덤 (1–5주차에 접힘, 6주차 없음)

1–5주차 경제 숫자는 그대로. 리튠: `Assets/Resources/Balance/FandomBalance.asset`. WeekStart / 정산 HUD: `충성 n/100   시청자 T0  팔로워 T1  정기 T2  코어 T3  슈퍼팬 T4`.

- 시작: T0 12, T1–T4 0, 충성 40/100. T0는 시작/라이브 시청자 바닥. 멤버십 해금은 기존 2주차 규칙. 해금 후 `membershipCount` = T3.
- 방송 후: Perfect ≥8 이면 T0→T1 2, T1→T2 1, 충성 +5. Perfect 4–7이면 T0→T1 1, 충성 +1. Miss ≥10이면 충성 −8, T2 −1(최소 0).
- 슈퍼팬 T4 두 명. **민준 (첫 도네)** 은 런의 첫 성공 슈퍼챗 후. 팬레터를 3번 정산에서 무시하면 떠남(충성 −12, 슈퍼챗 보너스 1일 소멸). **하은 (매일 오는 야간)** 은 2일차 아침. 3미스 스트릭이면 상처, 그날 팬레터를 안 하면 떠남(충성 −15). 있으면 WeekStart / 정산에 이름이 뜬다.
- 정산 **팬레터**: 민준/하은이 있으면 편지 카드. **답장하기**는 기존과 같이 충성 +4, 멘탈 +8(100 캡), 공짜, 하루 1회. **나중에**는 접기만 — 민준은 3번 무시하면 떠나고, 하은은 상처 난 날 안 답하면 떠남.
- 청구 슬램 때 충성 ≥60이면 `충성/2`% 로 팬 지원금 `3000 + T3×200 + T4×4000`(최소 3,000 최대 20,000). 빚 전환 전에 적용. 성공하면 WeekStart에 금색 **팬 지원금** 스플래시. 실패·미굴림은 스플래시 없음.
- 3주차 첫날(11일) 한 번 **콘텐츠 편중 갈등** 두 장 카드. 특별방송으로 달래기(멘탈 −10, 충성 +8) 또는 내 스타일대로(T2 −2, 충성 −10, 다음 추가 위협 +2,000). 건너뛸 수 없고, 고른 뒤 한 줄 결과가 뜬다.
- 4주차+ 에이전시 설립 후 정산에 **기본 자동응답** 켜기/끄기 카드가 한 번. 매일 ₩8,000은 그대로. T0/T1 케어는 자동. 민준/하은은 진짜 팬레터가 필요하고, 자동만 켜고 팬레터를 안 내면 충성 −1.

## 콘텐츠 타입 (1–5주차에 접힘, 6주차 없음)

1–5주차 청구/승리 숫자는 그대로. 리튠: `Assets/Resources/Balance/ContentBalance.asset`. WeekStart에서 청구 후, 방송 켜기 전에 오늘 콘텐츠를 반드시 고른다. 라이브는 화살표 / Space QTE와 화면의 긍정/공감/웃음/감사 버튼. 타입은 채팅 가중치·타이밍·수입 배율만 바꾼다. HUD와 정산에 오늘 픽이 보이고, 세이브에 남는다.

- **토크:** 긍정/공감 위주, 수입 ×1.0, 멘탈 −6, 팔로워 T0→T1 / T1→T2 쪽.
- **게임:** 웃음/트롤 위주, 수입 ×1.15, 멘탈 −10, Perfect 시청자 스파이크, Miss 시청자 손실 더 큼.
- **노래:** Perfect 창 ×0.85, 수입 ×1.1, 멘탈 −8, 슈퍼챗 간격 짧아지고 횟수 +2.
- **리액션:** 채팅 느림 (스폰 간격 ×1.35), 수입 ×0.9, 멘탈 −4, Miss < 8이면 종료 충성 +2.

## 조작 (PC 키보드)

| 키 | 행동 | 채팅 |
| --- | --- | --- |
| **←** | 긍정 | 파랑 일반 |
| **↓** | 공감 | 초록 질문 |
| **→** | 웃음 | 빨강 트롤 |
| **↑** | 감사 | 골드 슈퍼챗 |
| **Space / Enter** | 슈퍼챗 차지 후 **떼면** 한 번만 판정 (홀드 연타 없음) | 골드 |
| **1–4** | 방송 중 이벤트 QTE (안티 웨이브 / 장비 렉, 빛나는 키) | 한 번 |
| **A/S/D/F · WASD** | 같은 판정 (별칭) | 화살표와 동일 |
| **←/↑ · →/↓** | 3주차 굿즈 홍보 / 4주차 스폰서 멘트 / 5주차 콘서트 퍼포먼스 | 각 주차 하루 1회 |
| **화면 버튼** | 긍정 / 공감 / 웃음 / 감사 / 슈퍼챗 (전폭 행, 세이프 에어리어) | 키와 같은 판정 |
| **Space / Enter** | 타이틀·프롤로그·WeekStart·정산에서 진행 | — |

채팅이 오른쪽 레인에서 히트바로 떨어질 때 색/타입에 맞는 키 또는 화면 버튼을 누른다. 말풍선은 긍정/공감/웃음/슈퍼챗마다 짧은 한국어가 섞인다. Perfect / Great / Good / Miss. Title / WeekStart / LiveStream / Settlement는 같은 웹캠·KRW 크롬을 쓴다. 라이브 HUD는 오늘 청구 vs 지금 수입을 재고, 하이프 2.5x와 민준/하은 말풍선을 보여준다. 오늘 콘텐츠(토크/게임/노래/리액션)는 라이브 첫 화면부터 색·웹캠·BGM으로 구분되고, WeekStart 카드가 같은 색을 미리 보여준다. 아침에 찍힌 추가 위협은 라이브에 장비 불안정 / 재연결 / 수수료 같은 표시만 남긴다(입력·추가 차감 없음).

## 플레이테스트 스킵 (에디터 / DEVELOPMENT만)

프로덕션 빌드에는 없다. 켜져 있으면 화면 오른쪽 위에 작은 **DEBUG** 라벨이 보인다. 메뉴 **파산 버튜버 → DEBUG**.

| 키 | 행동 |
| --- | --- |
| **F10** | 오늘 남은 방송을 **평균 성공**으로 건너뛰고 정산. 정산 화면에서는 다음날 아침. 수입 ₩28,000 = 문서화된 1주차 평균 밴드 ₩24,000–₩32,000의 중간값. AFK 아님, 하이프 익스플로잇 아님. 스킵 후 세이브. |
| **F9** | 다음 주차(2/3/4/5) 첫날 아침. 2주차 입장 보너스 +₩15,000 / 빚 −₩10,000 / 멘탈 100. 이미 그 날을 지난 현금·빚은 유지. 클리어 조건만 맞춤(3주차부터 멤버십, 4주차부터 아크릴, 5주차부터 에이전시). 점프 후 세이브. |

## 숫자 리튠

잠긴 1주차 숫자는 데이터로 빠져 있다. 코드 상수에 의존하지 말고 에셋을 고친다.

- `Assets/Resources/Balance/Week1Balance.asset` — 현금/부채/청구/판정/슈퍼챗/하이프/멘탈
- `Assets/Resources/Balance/Week2Balance.asset` — 2주차 청구/위협/멤버십/클립
- `Assets/Resources/Balance/Week3Balance.asset` — 3주차 청구/위협/라이벌/아크릴/홍보
- `Assets/Resources/Balance/Week4Balance.asset` — 4주차 청구/위협/에이전시/주니어/스폰서
- `Assets/Resources/Balance/Week5Balance.asset` — 5주차 청구/위협/랭킹/콘서트/엔딩
- `Assets/Resources/Balance/FandomBalance.asset` — 팬덤 티어/충성/지원금/갈등/자동응답
- `Assets/Resources/Balance/ContentBalance.asset` — 콘텐츠 4종 수입/멘탈/채팅 가중치
- `Assets/Resources/Balance/ChatCatalog.asset` — 한국어 채팅 카피
- 런타임 폴백: `Week1Balance.ApplyLockedWeek1Defaults()` / `ChatCatalog.ApplyDefaults()`

훅업 확인: 에디터 메뉴 **파산 버튜버 → Verify Week 1 Hookup**.  
헤드리스 검증: `python3 Tools/verify_week1.py`

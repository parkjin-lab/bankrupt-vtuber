# 파산 버튜버

90초 라이브 한 판으로 이번 주 청구를 막거나, 못 막으면 끝나는 세로 2D 프로토타입이다.

**Unity 6000.5.9f1** (`b57deb96f08d`) · **`Assets/Scenes/Title.unity`** · 브랜치 **`cursor/week1-playable-loop-133f`**

숫자·연출은 이 브랜치에 박혀 있다. 노트북 클론에서는 에디터만 맞추면 바로 플레이할 수 있다.

## Unity에서 열기

1. Unity Hub에서 **6000.5.9f1** (`b57deb96f08d`)을 설치한다.
2. **Add** → 이 저장소 루트를 연다. Built-in 2D, URP/HDRP 없음.
3. `Assets/Scenes/Title.unity`를 연 뒤 Play.

씬 네 장: `Title` → `WeekStart` → `LiveStream` → `Settlement`. 타이틀 버튼이 루프를 탄다.

## 조작

라이브에서 화살표 · A/S/D/F · WASD · 화면 패드가 같은 노트에 들어간다. 패드 탭은 **입력됨**이 뜬다.

| 입력 | 동작 |
|---|---|
| ← / A / 왼쪽 패드 | 긍정 |
| ↓ / S / 아래 패드 | 공감 |
| → / D / 오른쪽 패드 | 웃음 |
| ↑ / F / W / 감사 패드 | 감사 |
| Space / Enter **떼면** 한 번 | 슈퍼챗 놓기 (홀드 연타 없음) |
| 1 / 2 / 3 / 4 | 이벤트 QTE (안티 웨이브 / 장비 렉, 빛나는 키) |
| 1일차 코치 | 새 런 첫 라이브만. 노트가 히트바에서 멈추고 **← 긍정** 같은 한 줄이 뜬다. 성공 3회 또는 8초면 끝. |

## 한 판 루프

**Title** → **WeekStart** 청구 슬램 → 콘텐츠 픽 → **90초 라이브** → **Settlement** 헤드라인 / 편지 / 주차 카드 → 클리어 또는 파산.

라이브 HUD에 있는 것:

- 지금 수입 · 오늘 청구 · 파산까지 — 슈퍼챗 ₩이 수입 칸으로 날아간다. 빗나가면 크랙.
- 떨어지는 채팅은 한국어 닉 + 대사. 민준 첫 도네는 스탬프.
- 하이프 중 금빛 워시 · 멘탈 위험/강제 종료 워시 · 시청 ± 팝업.
- 위협 오버레이 · 이벤트 카드 · 청구를 넘기는 순간 **청구 커버** 금빛 슬램(한 판 한 번, 이후 초록 고정).

정산: **오늘 헤드라인** → 편지 → 그 주 시스템 카드. 주 클리어/파산은 전용 화면.

## 2~5주차 (있는 그대로)

1주차는 청구·멘탈·콤보·이벤트만. 2주차부터 아래가 정산/라이브에 붙는다. 숫자는 코드에 잠겨 있다.

- **2주차** — 멤버십 스플래시 · 클립 카드.
- **3주차** — 라이벌 듀얼 · 아크릴 해금 · 홍보 카드.
- **4주차** — 에이전시 · 후배 · 스폰서 카드.
- **5주차** — 랭킹 · 콘서트 · 엔딩 루트(`EndingRoot`).

이름 팬은 **민준** / **하은**. 일반 채팅 닉은 `밤샌사람` 같은 풀. 콘텐츠 네 장(토크/게임/노래/리액션)은 청구 슬램 뒤 고른다.

## 플레이테스트 키

에디터 / DEVELOPMENT 빌드만. 켜지면 오른쪽 위에 **DEBUG  F9 다음 주  F10 오늘 스킵**.

- **F9** — 다음 주차(2/3/4/5) 첫날 아침으로 점프한 뒤 세이브. 5주차면 무시.
- **F10** — 남은 방송을 평균 성공 **₩28,000**으로 건너뛰고 정산. 정산 화면에서는 다음날 아침. 하이프 익스플로잇 아님.

## 검증

```bash
python3 Tools/verify_week1.py
```

에디터 메뉴 **파산 버튜버 → Verify Week 1 Hookup** 도 같은 스크립트를 돌린다.

1주차 시작 현금 ₩45,000 / 부채 ₩50,000, 매일 고정비 ₩22,000, 파산 부채 ≥ ₩180,000. 리튠은 `Assets/Resources/Balance/` 에셋.

## 범위 밖

6주차·글로벌 투어 없음. 타이틀은 1주차 루프만 말한다.
